## 一句话

为每个 Member 按角色可选配模型（`assistant` / `embedding` / `decision` / `extraction`）：助手在后台做 L1 分类 + 关键词 + 多维 facet、L2 结构化压缩 + 分级汇总、L3 拓扑索引 + 跨代图；嵌入角色提供向量召回；决策与抽取角色分别判定陈旧关系、产出结构化事实。发送前用本地确定性主题提取做精确 + 模糊 + 向量（上一轮缓存）+ facet 多路检索（一次 RRF 合并），把 top-3 以 `<recall-snapshot>` 追加到消息尾部；新信息与历史冲突时写“取代链”，旧版本默认不召回。压缩只走既有 compaction 事务，以低频 epoch 提交换取缓存可控。
